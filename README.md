# لوحة مدير النظام (super_admin_web)

إدارة النظام: إحصائيات النظام (التخزين، الأجهزة، الجلسات، المعالجة)، حساب صاحب المعهد، أجهزة
الطلاب (المكان الوحيد لإعادة تعيين الجهاز)، سجل التدقيق (قراءة فقط)، إعدادات النظام، إضافة
إلى كل ما يديره صاحب المعهد.

React 19 · Vite · TypeScript · TanStack Query · React Hook Form + Zod · Tailwind CSS 4 · i18next (عربي/إنجليزي).

## التشغيل

الـ backend يجب أن يعمل (`npm run dev` داخل مجلد backend). ثم داخل هذا المجلد:

```bash
npm install      # مرة واحدة فقط
npm run dev
```

افتح http://localhost:5174 — الدخول: `0900000000` / `Admin12345`.

## ملف `.env`

| المتغير | المعنى |
|---|---|
| `VITE_API_BASE_URL` | عنوان الـ API للتطوير المحلي (`http://localhost:4000`). لا يُستخدم على السيرفر |

## رفع الفيديوهات والملفات

- **ضغط الفيديو قبل الرفع** (خيار في نافذة الرفع، مفعّل افتراضياً): يصغّر فيديو الهاتف عادةً إلى
  نحو ربع حجمه مع بقائه واضحاً، فيصبح الرفع أسرع. يتم على جهازك قبل الرفع (أبقِ الصفحة مفتوحة
  أثناء الضغط فقط).
- **متابعة الرفع بعد إغلاق الموقع** (Chrome و Edge): بعد بدء الرفع يمكنك إغلاق الموقع، ويكمل
  المتصفح الرفع وحده، ويظهر التقدم عند عودتك.
- **الملفات**: تُصغَّر الصور الكبيرة، وتُضغط ملفات PDF و TXT أثناء الإرسال فقط؛ الطالب يستلم الملف
  نفسه بصيغته الأصلية.

الميزتان الأوليان تعملان على موقع بـ HTTPS (قيد من المتصفحات). ما دامت اللوحة على عنوان IP بدون
HTTPS، يمكن تفعيلهما على جهاز صاحب المعهد مرة واحدة: افتح في Chrome
`chrome://flags/#unsafely-treat-insecure-origin-as-secure` (في Edge: `edge://flags/...`)، واكتب
عنوان اللوحة (مثلاً `http://163.245.221.210:6001`)، واختر **Enabled** ثم أعد تشغيل المتصفح.
بدون ذلك يعمل الرفع كما كان: بلا ضغط للفيديو، ويجب إبقاء الموقع مفتوحاً حتى يكتمل.

## الرفع على السيرفر (Docker)

شغّل الـ backend أولاً (مشروعه ينشئ شبكة Docker المشتركة `edu-platform`). ثم داخل هذا المجلد على
السيرفر:

```bash
docker compose up -d --build
```

تعمل اللوحة على `http://IP-السيرفر:6002`. الـ Docker يبني الموقع ثم يخدمه عبر Nginx الذي يمرّر
طلبات `/api` إلى الـ backend داخل Docker — لا حاجة لأي إعداد لعنوان الـ API.
للتحديث بعد `git pull`: نفس الأمر. التفاصيل: `backend/docs/deployment.md`.
يُنصح بقصر الوصول لهذه اللوحة على عناوين IP معروفة.
